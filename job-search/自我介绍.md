面试官好，我是刘奕晨，中国传媒大学软件工程本科，工作五年。前三年在华侨城做园区业务的 Web、桌面端和小程序。2024 年 7 月到腾娱，先做 QQ 频道的 H5、小程序、Web 和运营后台。其中技术债治理后台是我从空仓库独立做到上线的。

2026 年 3 月我转全栈，现在和企业里另一位同事一起做 AI 编程平台 QPilot Code。用户用自然语言提需求，Agent 在云端沙箱里写代码、起预览、提交 Git，再部署成可以访问的应用。我是两名主力开发之一，平级分工。我负责沙箱 Git、预览、部署、上传和身份、Skills、会话，前端工作台也是我们在做。内置 Skills 会同步进沙箱，按 SDK 的方式按需加载。部署不再让模型自己发请求，改成带令牌的 MCP 工具，令牌和这一次操作绑在一起。

其中两件事是我从方案做到上线的。一件是模型写 Git：后端签发短期令牌，模型只能拿令牌调接口，凭证不进沙箱。换沙箱之后，每个 Git 接口的多条命令合成一次往返，状态检查从十多次降到一次。另一件是预览：处理过端口被占、沙箱回收后不启动、重试时状态来回跳。缺文件时，恢复时间从大约一分钟缩到大约六秒。会话上，模型输出时用户可以继续输入，也可以改完消息重发，并清掉模型侧的旧上下文。

我的前端底子是多端和中后台，最近在做能上线的 Agent 应用，前后端都写，主要是 TypeScript、React 和 Node.js。接下来还是想做 AI 应用和 Agent 全栈，人在深圳。
