## A 版 · Agent 岗（90 秒）

| 时间 | 画面 | 台词 |
|---|---|---|
| 0–10s | 左对话、右空预览 | “这是我按我们平台的链路**复刻的最小版**：对话改码 → 隔离执行 → 实时预览。” |
| 10–30s | 输入需求 → 流式 + 工具调用卡片 | “模型边流式输出边发工具调用，**每次调用的参数和结果都可见**，不是黑盒。” |
| 30–55s | 预览出现 | “工具在**隔离目录**执行，改完自动起 dev server，通过代理嵌进 iframe。” |
| 55–75s | 再改一次，预览自刷新不闪 | “第二次改动不用点任何按钮。难点是**判定新内容真的生效才切换**，否则会闪回旧版本。” |
| 75–90s | 定格 | “生产里我主要负责 ___；这里简化了 ___。边界：**断线能续，进程挂了不能续**。” |

## B 版 · 前端岗（90 秒）

| 时间 | 画面 | 台词 |
|---|---|---|
| 0–10s | 左表单、右卡片预览 | “这是我复刻的 **schema 驱动动态表单**，还原了运营后台模板卡片配置页的核心。” |
| 10–30s | 切两个下拉框 → 字段增减 | “字段清单由配置决定，两个下拉框决定出现哪些字段——**变的是清单，不只是值**。” |
| 30–50s | 指表单 / 预览 | “表单和预览拆开，只通过数据契约通信；同一组件支持新建与编辑，**编辑态数据会盖住配置默认值**。” |
| 50–75s | 打开“错误模式”开关 | “这里留了个开关还原当时的 bug：`memo` 比较函数只比‘值’没比‘字段清单’，编辑态下值没变、清单变了，该重渲染的被跳过。” |
| 75–90s | 收口 | “当时用配置默认值做比较；**复盘更稳的是把清单纳入比较，或用 key 重建**——比较函数是白名单，漏一个就是 bug，还不报错。” |

**为什么留“错误模式”开关**：把 bug 变成**可演示**，面试官立刻信你真踩过。

## 复刻最小清单（只做"够演 90 秒"）

**A 版**
- 输入框 + SSE 流式（假 token 流即可，重点在呈现）
- 工具调用卡片：`read_file` / `write_file`，显示参数与结果
- 真执行：`child_process` + 独立目录（简化沙箱）跑 `npm run dev`
- iframe 预览 + **新内容生效判定**后切换（不要直接 reload）
- 可选：`EventSource` 断线重连

**B 版**
- schema 配置：字段清单 + 默认值
- 两个下拉框驱动字段增减
- 右侧预览同步
- **错误模式开关**（对比修复前后）

**不做**：登录、权限、多项目、真实模型调用（假数据流，省 token 也省等待）
