## LC 3 · 最长无重复子串（滑动窗口）

```js
function lengthOfLongestSubstring(s) {
  let left = 0, max = 0;
  const map = new Map();                  // 字符 -> 最近出现位置
  for (let right = 0; right < s.length; right++) {
    const ch = s[right];
    if (map.has(ch) && map.get(ch) >= left) {
      left = map.get(ch) + 1;             // 把重复字符挤出窗口
    }
    map.set(ch, right);
    max = Math.max(max, right - left + 1);
  }
  return max;
}
```

**核心模型**：一个框，**框里永远无重复**。右边界一直吃，吃到重复就移动左边界把它挤出去。两个指针都**只往右走**。

**唯一的坑**：`left` 不能直接 `= 上次位置 + 1`，必须确认“上次位置还在窗口里”：

```
"abba"：到了最后一个 a，它上次在 0，但 left 已经是 2
直接跳 → left 从 2 退回 1 → 框变成 "bba"，有重复 → 错
正确 → 0 < left，说明早已出框，left 不动
```

**`>= left` 比 `Math.max` 更好的原因**：它直接表达真实语义——**“这个字符还在框里吗”**，而不是“算一下谁大”。

**手推校验点**：`right=5, left=3` 时框是 `3~5`（三个字符），长度 `5-3+1=3`。**两个端点都算**，别把 right 当成 4。

**复杂度**：时间 **O(n)**（`right` n 步 + `left` 最多 n 步，只前进）；空间 **O(min(n, 字符集))**，小写字母即 O(1)。

## LC 15 · 三数之和（排序 + 双指针 + 三处去重）

```js
function threeSum(nums) {
  nums.sort((a, b) => a - b);
  const res = [];
  for (let i = 0; i < nums.length - 2; i++) {
    if (nums[i] > 0) break;                             // 剪枝
    if (i > 0 && nums[i] === nums[i - 1]) continue;     // 去重 ①
    let l = i + 1, r = nums.length - 1;
    while (l < r) {
      const sum = nums[i] + nums[l] + nums[r];
      if (sum === 0) {
        res.push([nums[i], nums[l], nums[r]]);
        while (l < r && nums[l] === nums[l + 1]) l++;   // 去重 ②
        while (l < r && nums[r] === nums[r - 1]) r--;   // 去重 ③
        l++; r--;
      } else if (sum < 0) l++;
      else r--;
    }
  }
  return res;
}
```

**三个设计点，缺一个就错**：

| 点 | 作用 |
|---|---|
| **排序** | 才能用双指针（`sum<0` 左移、`sum>0` 右移），也才能跳过重复 |
| **`nums[i] > 0` 剪枝** | 排序后最小的大于 0，后面不可能凑出 0 |
| **三处去重** | `i` / `l` / `r` 各自跳过重复，否则同一个答案重复收集 |

**为什么 `sum===0` 之后必须跳重复**：`[-2,0,0,0,2]` 里如果不跳，`l` 会在三个 0 上各命中一次，同一组 `[-2,0,2]` 被 push 三次。

**复杂度**：时间 **O(n²)**（外层 n × 内层双指针 n），空间 **O(1)**（除输出；排序栈 O(log n) 另计）。
