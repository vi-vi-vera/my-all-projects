## LC 141 · 判环（快慢指针）

```js
function hasCycle(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {      // ← 边界：空链表 / 单节点 / 无环
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
}
```

**为什么一定相遇（必问，别说"一快一慢所以能追上"）**：
进入环后，快指针每轮比慢指针**多走 1 步** → 两者距离每轮减 1 → `d → d-1 → … → 0`，**步差是 1 所以不会跳过**。
反例加分：若 fast 一次走 3 步、slow 走 1 步，步差 2，距离可从 1 直接变 -1，**可能永远跳过**。

复杂度：时间 O(n)，空间 **O(1)**。

## LC 142 · 找入环点（用 141 + 一个代数性质）

```js
function detectCycle(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) {
      let p = head;
      while (p !== slow) { p = p.next; slow = slow.next; }  // 头 + 相遇点 同速
      return p;
    }
  }
  return null;
}
```

**推导（要能白板写）**：
```
a = 头→入环点，b = 入环点→相遇点，L = 环长
slow 走 a+b，fast 走 a+b+nL，且 fast = 2*slow
→ a+b = nL  →  a = nL - b = (n-1)L + (L - b)
```
**结论**：`a`（头→入环点）== `L-b`（相遇点→入环点）。
**所以**：一个指针从头、一个从相遇点，同速走，相遇处即入环点。

易错：**别在 141 的循环里直接 return**，要进"相遇"分支再走第二段。

## LC 20 · 有效括号（栈）

```js
function isValid(s) {
  const stack = [];
  const pairs = { ')': '(', ']': '[', '}': '{' };
  for (const ch of s) {
    if (ch === '(' || ch === '[' || ch === '{') stack.push(ch);
    else if (stack.length === 0 || stack.pop() !== pairs[ch]) return false;
  }
  return stack.length === 0;
}
```

**三个 false 缺一不可**：
1. 右括号来了但**栈空**（`"]"`）
2. 栈顶**不配对**（`"(]"`）——`pop()` 返回栈顶，直接比
3. **遍历完栈非空**（`"("`）——最后 `return stack.length === 0`

细节：`stack.length === 0 || stack.pop() !== ...` 依赖**短路**，栈空时不会 pop。

复杂度：时间 O(n)，空间 O(n)。
