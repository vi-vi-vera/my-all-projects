# 卡 24 · 系统设计⑤ 评测平台（8 分钟）

> 定级：L2（方法论扎实，平台分层需再口述一次）｜ 2026-11-24（D8）
> **口径：业务上没建正式回归集，只有个人 Demo 的 10 条 golden cases。** 讲设计，不包装成做过。

## 3 句骨架

1. **AI 的输出没有唯一正确答案**，所以判分不是一个断言，是**四层金字塔**：确定性检查 → 规则断言 → 语义判分 → 人工抽检。
2. **能下沉到确定性的，绝不交给模型判**——便宜、稳定、无偏差。
3. **平台的价值在"改动前后可比"**：固定数据集 + 版本化 + 逐条 diff，而不是一个总分。

## 一、为什么不能用 `assert.equal`

| 原因 | 说明 |
|---|---|
| 输出非确定性 | 同输入不同输出（采样），跑一次不算数 |
| 没有唯一解 | 一个需求有多种合理实现 |
| 评测对象是行为 | 改对了没？改多了没？有没有引入风险？ |
| 评测本身有成本 | 起沙箱、调模型，不能无限跑 |
| 环境也有噪声 | 依赖版本、网络、沙箱状态 |

**关键词匹配为什么不能当主判据**：表达多样性（"已删除" vs "已经清理掉了"）、否定句（"不要修改"命中"修改"）、可被堆词刷分。它只能做兜底信号。

## 二、判分金字塔

```
L1 确定性检查   能编译？测试过？退出码 0？JSON 能 parse？
L2 规则断言     必须调用了某工具 / 不能碰某文件 / diff 行数上限 / 字段齐全
L3 语义判分     LLM as judge（rubric 固定 / A-B 换序去偏）、embedding 相似度
L4 人工抽检     标一小批，用来校准 L3
```

对 Agent 还要加一层 **轨迹判分**：结果对 ≠ 过程对（工具选错但碰巧成功、绕十轮才成）。

## 三、评测方法论（这部分已成型，来自实践）

**回归集构成**：正常场景 + 边缘场景 + **历史 bad case**（最值钱，最容易复发）

**每次改动跑完看四件事**：
1. **硬标准**过没过（不过直接打回）
2. **整体通过率**变化
3. **逐条 diff**：成功→失败（回归！）、失败→成功（改进）
4. **目标项升没升、非目标项降没降**

**五个必须补的工程概念**：

| 概念 | 为什么 |
|---|---|
| **非确定性 → 跑 N 次** | 单次通过 ≠ 稳定，要看通过率/flaky 率 |
| **样本量 → 别过度解读** | 10 条里变 1 条可能是噪声 |
| **judge 自身的偏差** | 偏爱长回答、偏爱前面的选项 → rubric 固定 + A/B 换序 |
| **防过拟合 / holdout** | 拿回归集调 prompt，分数必涨但线上不涨 |
| **成本分层** | 全量跑贵 → 改动跑 smoke，发版跑全量 |

## 四、烟雾测试怎么设计（5 分钟出结论）

**不要随机抽**——随机可能抽不到最危险的 case。**固定 + 按风险分层**：

| 优先级 | 抽什么 |
|---|---|
| P0 | 硬标准 / 安全类（越权、删文件） |
| P1 | 核心链路（最常用场景） |
| P2 | **历史 bad case**（最易复发） |
| P3 | 随机几条（防只针对固定集优化） |

**5 分钟靠三件事**：并发跑 + 每条只跑 1 次 + 失败短路（L1/L2 先跑，挂了不再调 judge）。

**还要判断影响面**：改的是工具调用逻辑，就别指望 smoke 覆盖，直接跑受影响的档位。

**差异阈值**：硬标准零容忍；软分允许 1~2 条抖动（判为噪声而非回归）。

## 五、平台六层

| 层 | 职责 |
|---|---|
| 用例管理 | 数据集、版本、标签分层（smoke/regression/edge/bad case）、**holdout 隔离** |
| 执行调度 | 并发、沙箱分配、重试、N 次重复、成本预算 |
| 判分引擎 | 四级金字塔、rubric 版本化、A/B 换序 |
| 结果分析 | 通过率、逐条 diff、按维度/标签切片、显著性 |
| 回归门禁 | CI gate：硬标准不过打回；软分看趋势 |
| 追踪复现 | 每条 case 关联 trace → bad case 一键重放 |

**切分理由**：**判分和执行分开**。执行管"便宜稳定地跑"，判分管"判得准"。混一起，换 judge 要改调度。

## 六、三个 trade-off

| 矛盾 | 选择 | 代价 |
|---|---|---|
| 自动判分 vs 人工 | 人工标小批校准自动判分 | 不是全量人工，仍有偏 |
| 覆盖面 vs 成本 | 分层触发（smoke / regression / 全量） | 小集漏掉的尾部风险 |
| 严格度 | **硬 gate 严、软分松** | 需要维护"哪些算硬标准"的清单 |
