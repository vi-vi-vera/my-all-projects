# 卡 26 · LC 二叉树三题：层序 / 深度 / 直径

> 定级：L4（三题一次写出，边界全过）｜ 2026-11-24（D8）
> 102 / 104 / 543。二叉树题的解法只有四种：**递归（前中后序）、BFS 层序、回溯、分治**。

## LC 102 · 层序遍历（BFS + 按层分组）

```js
function levelOrder(root) {
  if (!root) return [];
  const res = [];
  const queue = [root];
  while (queue.length) {
    const level = [];
    const size = queue.length;        // ★ 关键：先固定「这一层有几个」
    for (let i = 0; i < size; i++) {
      const node = queue.shift();
      level.push(node.val);
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    res.push(level);
  }
  return res;
}
```

**唯一的坑**：`size` 必须在进 for 之前取。否则循环里边 push 下一层，`queue.length` 会变，把下一层当本层。

**复杂度**：
- 时间 **O(n)**（每个节点进出队列一次）
- 空间 **O(w)**（w = 最大层宽，最坏 O(n)）

**`shift()` 的坑**：JS 数组 `shift()` 是 **O(n)**（后面元素全要前移），所以实际退化成 O(n·w)。改法：
```js
let head = 0;
while (head < queue.length) {
  const size = queue.length - head;
  for (let i = 0; i < size; i++) { const node = queue[head++]; ... }
}
```

> **不要答「复杂度是 2 的 n 次方」**——那是满二叉树的**节点数上限**，不是复杂度。

## LC 104 · 最大深度（递归 30 秒题）

```js
function maxDepth(root) {
  if (!root) return 0;
  return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}
```
O(n) 时间，O(h) 栈空间（h = 树高；退化成链表时 O(n)）。

## LC 543 · 直径（后序 + 全局 max）

```js
function diameterOfBinaryTree(root) {
  let max = 0;
  function depth(node) {
    if (!node) return 0;
    const left = depth(node.left);
    const right = depth(node.right);
    max = Math.max(max, left + right);   // ① 经过本节点的路径【边数】
    return Math.max(left, right) + 1;    // ② 返回给父节点的是【深度】，要 +1
  }
  depth(root);
  return max;
}
```

**两个必须说清的点**：

1. **为什么是 `left + right` 不加 1**：直径算**边数**，左深度 + 右深度 已经是“从左最深到右最深”经过的边数；`+1` 是节点数口径，会多算。
2. **为什么必须用全局 max**：最长路径的**最高点可能不在根**——可能整个落在左子树里。如果只在根算 `left+right`，会漏。

**这就是“后序 + 全局变量”模板**：后序负责自底向上汇总，全局变量负责收集“以任意节点为顶点的最优解”。

复杂度 O(n) 时间，O(h) 空间。

## 三题共性

| 题 | 遍历方式 | 关键不变量 |
|---|---|---|
| 102 | BFS | 队列里**只装本层**（靠 size 快照） |
| 104 | 后序递归 | 返回“以我为根的深度” |
| 543 | 后序 + 全局 | 返回深度，**顺手用 left+right 更新答案** |

> 一句话：**104 是“返回什么”，543 是“返回什么 + 顺手记录什么”。** 后者是树形 DP 的通用套路（如 124 最大路径和）。
