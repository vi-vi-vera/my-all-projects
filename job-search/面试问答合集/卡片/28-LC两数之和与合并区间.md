# 卡 28 · LC 1 两数之和 / LC 56 合并区间

> 定级：L4（两题写出，LC1 需记住「return 放循环外」）｜ 2026-11-25（D9）

## LC 1 · 两数之和（返回下标）

```js
function twoSum(nums, target) {
  const map = new Map();          // num -> i（存什么就必须查什么）
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (map.has(need)) return [map.get(need), i];
    map.set(nums[i], i);
  }
  return [];                      // ← 必须在循环外！
}
```

**三个易错点（今天全踩了）**：

| 错 | 后果 |
|---|---|
| `return []` 写在 for 里 | 第一轮没命中就退出，只看了第一个元素 |
| `return [idx, 1]` | 该是 `i` |
| 存补数、查补数 | `target-nums[j] === target-nums[i]` → 只有重复元素才命中 |

**两个正确变体**（存什么查什么，别混）：
- A：存 `num`，查 `target-num`
- B：存 `target-num`，查 `num`

**为什么边遍历边存**：先全存再查会**匹配到自己**（`target = 2*nums[i]` 返回 `[i,i]`）。

复杂度和：**O(n) / O(n)**。

## LC 56 · 合并区间

```js
function merge(intervals) {
  if (!intervals.length) return [];
  intervals.sort((a, b) => a[0] - b[0]);        // 按起点排

  const res = [[...intervals[0]]];              // 拷贝，别持有入参引用
  for (let i = 1; i < intervals.length; i++) {
    const cur = intervals[i];
    const last = res[res.length - 1];
    if (cur[0] <= last[1]) {
      last[1] = Math.max(last[1], cur[1]);      // ← 必须 max
    } else {
      res.push(cur);
    }
  }
  return res;
}
```

**三个关键点**：

1. **必须先排序**：不排序，重叠区间可能不相邻，无法一趟扫完。排序 = O(n log n)，**这就是总复杂度的来源**。
2. **`Math.max` 不能省**：`[[1,10],[2,3]]` 直接 `last[1] = cur[1]` 会得到 `[1,3]`，区间反而变小（被包含的情况）。
3. **`cur[0] <= last[1]` 用 `<=`**：`[[1,4],[4,5]]` 端点相接也算重叠。

**复杂度**：时间 **O(n log n)**（排序主导），空间 **O(n)**（结果数组；排序栈 O(log n) 另计）。
**面试口径**：「不排序做不到 O(n)，因为必须先让重叠的区间相邻。」

**副作用提醒**：`sort` 原地改数组，`res = [intervals[0]]` 持有引用后再 `last[1] = ...` 会**改入参**。生产代码要先拷贝（`[[...intervals[0]]]` 或整体深拷贝）。

## 盲测二轮记录（2026-11-28，D12）

第一轮盲写 **LC 56 挂**，两个错全是手滑（概念没错）：

| 错 | 后果 |
|---|---|
| `intervals.sort((a,b)=>a-b)` | a、b 是数组 → **NaN** → 乱序输入根本没排，得到 `[[8,10],[15,18,null,18]]` |
| `left[i] = Math.max(...)` | `i` 是循环下标不是区间下标，`i=1` 碰巧对、`i≥2` 把区间写成 3 元素 → `[[1,4,5]]` |

**二轮重写 11/11 边界用例全过**（乱序、端点相接、被包含、三段合并、空数组）。

> 教训：**盲测抓的就是「以为会了、一写就错」**。sort 比较器、下标写错、return 位置这类，靠看卡过不了，必须手写。
> 顺带记住：`res = [intervals[0]]` 持有引用会改入参，生产里要拷贝。
