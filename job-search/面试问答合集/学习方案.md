## 一、先把「掌握」定成可检验的四级

| 级别 | 标准 | 检验方式 |
|---|---|---|
| L1 认得 | 看得懂文档，知道有这回事 | —— |
| L2 能讲 | 3 分钟讲完，有结构、有自己的案例 | 不看稿口述录音 |
| L3 抗追问 | 连续两层追问不倒，说得出 trade-off 和「我们没做」的边界 | 我扮演面试官连追 3 问 |
| L4 能写 | 现场写出可运行的最小实现 | 白板/编辑器，25 分钟内 |

**本次目标**

- AI 专项主线题 → **L3**（1.0 / 1.1 / 1.3 / 1.4 / 1.8 / 1.9 / 3.3）
- 加分题 → **L2**（1.2 / 1.5 / 1.6 / 1.7 / 1.10 / 1.11）
- Python 5 个指定件 → **L4**
- 前端八股 + 手写题 → **L2**；算法只求「30 分钟内出可用解」，不求最优

> 判定口径：**说不出来 = L1**，不管你看过多少遍。这张表每天更新。

## 二、方法：五步循环（AI 主线每天这么走）

1. **我先问，不给答案** —— 你先用自己的话说，暴露真实水平
2. **我只补你答不出的那一层** —— 不整段念文档，你会的跳过
3. **追问两层** —— 「为什么这么做」「不做会怎样」「换个场景呢」
4. **收口成一张卡** —— 3 句骨架 + 2 个 trade-off + 1 句边界话术
5. **隔日盲测** —— 第二天开头 5 分钟，不看卡复述上一个主题

**补课协议**：你说「这块我没有」→ 我直接给完整版，不再追问；你答得含糊 → 我先问「是没有还是想不起来」，再决定补知识还是改结构。

**每日卡片模板**（存 `卡片/NN-主题.md`，面试前只翻卡片）

```
主题：
3 句骨架：①  ②  ③
我挂的案例：（案例 N / 具体细节）
trade-off：A 换 B；C 换 D
边界（诚实说）：我们没做 ___，如果做我会 ___
最容易被追死的一问：___ → 答：___
```

### 降级规则（时间不够时按这个砍）

1. **只有 45 分钟**：AI 主线保满 → 前端只翻昨天的卡（5′）→ 算法只口述思路不写
2. **只有 30 分钟**：今天什么都不做，只做盲测 + 错题本盲写（保记忆，不追新）
3. **约面了**：当天三段全让位 → 该岗 JD 考点 + 自我介绍 + 项目故事三件套

## 五、绝对不能编的边界清单（说错比说不会更致命）

1. 业务上**没建正式回归集** —— 只有个人 Demo 的 10 条 golden cases
2. 平台是**单 Agent + Skills**，没有多 Agent 编排
3. 长期记忆 **线上一版没上** —— 实现完成在 `dev/wecom-bot-dispatch` 分支、未合主干。说「dev 分支做完了一版」，**不要说「线上在做 / 还在测试」**
4. **没做过 RAG**，也没微调
5. **没做多模型路由 / 生产级横向评测**，深度用过的是 Claude 一家
6. LangChain 系**没上过生产**（生产是 Claude Agent SDK）
7. git-write 受控令牌是**已实现未接前端的设计方案**，不是线上现状
8. Python 是**落过 demo，生产深度在 Node**

> 统一句式：「这块我们没做。如果要做，我会 ___，代价是 ___。」
> —— 先给现状，再给方案，最后给代价。面试官要的是判断力，不是你做过一切。
