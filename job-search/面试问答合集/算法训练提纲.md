# 算法训练提纲（保底前端线用）

> 定位：**保底前端线的最小算法集**，不是系统刷题。AI/Agent 线不考这些（那边的手写题见提纲 4.9）。
> 目标：30 分钟内给出**可用解**，不追求最优解。答出思路 + 边界处理 = 过。
> 总量：约 30–35 题 + 10 个手写函数。第二周启动，每天 30–40 分钟封顶，AI 线有面试排期时立刻让位。

## 优先级说明

- **第三梯队（手写题）权重最高**——前端面的「算法」大半是手写函数，且和你的案例能串（Promise 系列 ↔ 案例 3 状态机）。
- 第一梯队每天出镜率最高；第二梯队中频但答砸致命。
- 标 ⭐ 的是必练；其余选练。

## 第二梯队：中频但答砸致命

- 无重复字符最长子串（3）：哈希 + 滑动窗口 ⭐
- 三数之和（15）：排序 + 双指针，去重是坑
- 盛最多水（11）：对撞双指针
- 二分查找（704）+ 旋转数组搜索（33）：二分只到这，别往下钻
- 岛屿数量（200）：网格 DFS，考代码组织
- 爬楼梯（70）+ 打家劫舍（198）+ 最大子数组和（53）：DP 最小集，能讲出状态转移即可

## Python 变体（AI 线现场编码可能指定 Python）

上面 ⭐ 里挑 5 道用 Python 重写一遍：
1. 反转链表（指针操作语感）
2. 二叉树层序遍历（collections.deque）
3. 两数之和（dict 就是哈希）
4. 异步并发池（asyncio.Semaphore / TaskGroup）
5. FastAPI SSE 接口（20 行内跑通）

## 练法

- **一次一道，25 分钟**：15 分钟写 + 10 分钟看题解。写不出直接看题解，标记隔天重写——别死磕，死磕是最大的时间坑。
- **错题本**：不能一次通过（含边界用例）就记下来，3 天后盲写重测。
- 只用 JS 和 Python，不开第三语言。
- 每题写完口述一遍复杂度——面试官必问，练成条件反射。

## 不练什么（两周内投入产出比全负）

- 图论、回溯全套、Hard 题
- 拓扑排序、并查集、单调栈全家桶
- Trie 树（前端面出现率极低）
- 任何「刷完 XX 题再投」的计划——投递不等刷题，边投边练
