|---|---|---|---|

底线 22K。现薪 15K，被问到如实说，然后把话题拉回职责和成果。个人技术岗，不投管理岗。地点只接受深圳或远程。

## 30 秒判断

按这个顺序看，前面一条不过就停，不必读完 JD。

1. **地点。** 深圳（含深圳混合办公）或远程。其他城市不投。
2. **月薪上限。** 看的是月薪里的 K，不是年终月数。
   - 上限写明低于 22K：不投。
   - 上限 22–24K：只有远程，或业务明显对口，才记入台账，状态写「贴底线」。
   - 面议：可以投。AI 线按 28–32K 报，前端线按 23–26K 报。约到沟通时先问预算。
   - AI 线正常投的区间：上限至少 25K，并且区间和 25–32K 有重叠。例如 20–35K、25–40K 可以投；13–20K、15–20K 不投。
   - 前端线正常投的区间：上限至少 23K，并且和 23–26K 有重叠。
3. **是不是个人贡献岗位。** 标题或职责以带团队、定编制、对业绩负责为主的，不投。写了「带 1–2 名同事」但仍以写代码为主的，可以看。
4. **硬性要求能不能对上。** 下面「直接跳过」里的任何一条出现在「必须 / 任职要求」里，就不投。「加分 / 优先」里出现，不影响投递。

## 直接跳过

- 模型训练、微调、CUDA、论文、算法竞赛是必须项。
- 必须精通 Java、Go、C++，且不接受 Node.js / TypeScript。
- 必须有公开 GitHub、开源项目或技术博客。目前没有可放的公开链接。
- 必须 8 年以上，或必须有管理经验。
- 初级、实习，或职级明显按 1–3 年定薪且上限低于 22K。
- 只做活动页、视觉还原，没有业务逻辑和工程要求。

## AI 线：什么岗位值得投

猎聘上深圳在招的职称主要是：AI 应用工程师（全栈 / 智能体）、Agent 全栈开发工程师、AI Agent 应用开发、资深全栈（AI Agent / AI Native）。搜索时用这些词。

**优先点开（匹配 A）**，职责里同时有下面两类：

- 在做能上线的 AI 应用：Agent、工具调用、MCP、工作流、沙箱、预览、部署，而不只是调一个聊天接口。
- 技术栈能接上：TypeScript、JavaScript、Node.js、React 或 Vue。JD 写「资深前端转 AI 全栈可投」的，优先。

这种岗位用 `简历-AI应用.md`，把 JD 发过来，按岗位改一版再投。

**可以投（匹配 B）**：

- 偏 RAG、知识库、Dify、Coze，同时要自己写业务代码，而不只是配工作流。
- 全栈岗位后端写 Python 或 FastAPI，但接受 Node，或前端占比高。
- 标题是高级前端，职责里 AI 只是加分项。这时改用 `简历-前端.md`。

B 级先用对应母版投。约到面试再按 JD 改。

**标题像、职责不像（匹配 C，不投）**：

- 主要工作是训练、评测模型、写论文。
- 只配 Dify / Coze，不写服务和页面。
- 后端限定 Java 或 Go，前端只是「了解即可」。

## 前端线：什么岗位值得投

搜索词：高级前端、资深前端、前端开发工程师。城市选深圳，或关键词加「远程」。

**匹配 A**：Vue 3 或 React，有复杂中后台、多端（H5 / 小程序）、工程化和发布要求，年限 3–7 年。用 `简历-前端.md`，JD 发过来再改一版。

**匹配 B**：技术栈对得上，但业务是活动、内容或内部系统，复杂度一般。用前端母版直接投。

**不投**：初级前端、只还原设计稿、纯管理的前端负责人。

同一家公司两条线都在招时，先投 AI 线。AI 线被拒或薪资上限不到 25K，再投这家的前端岗。

## 投递节奏

每周先做 AI 线：点开约 8 个 JD，按上面的规则筛，目标投出 4 个。前端线作为补位，每周再投 2 个。数量不够就放宽到 B 级，不放宽地点和 22K 底线。

投出之后，台账状态改为「已投」。5 个工作日没有回复，状态改为「无回复」，不重复投同一岗位。

## 沟通时的薪资说法

对方问现薪：15K。

对方问期望：

- AI 线说 28–32K。对方还价，25K 以上可以谈。
- 前端线说 23–26K。22K 只在远程或业务明显更好时接受。
- 对方让你先报价，就按上面的对外口径说。对方已经给出区间，确认区间上限是否包含月薪，再决定继续或停止。
