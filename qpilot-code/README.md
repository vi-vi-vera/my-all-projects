## 项目一句话

QPilot Code Agent 面向企业 AI 编程场景，把设计稿和自然语言需求转成可预览、可部署的多框架前端代码；后端负责 Agent 执行、沙箱、Git、部署和观测，前端负责聊天、预览、部署面板和工具调用可视化。

## 使用建议

1. 先读 `project-context.json` 建立 backagent / backagent-web 双项目结构。
2. 再读 `interview-prep.zh.md` 准备项目介绍和关键 QA。
3. 用 `knowledge-map.zh.md` 补齐 AI Agent、沙箱、SSE、Git 写回、部署等知识点。
